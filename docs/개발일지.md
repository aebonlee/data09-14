## 결정과 이유

- **표준 라이브러리 + openpyxl(선택)만 씁니다.** 폐쇄망에서는 패키지 설치가 어려우므로 CSV·DB·판정·HTML 보고서는 표준 라이브러리로만 동작하게 하고, 엑셀 보고서만 openpyxl 이 있을 때 만듭니다. 없으면 HTML 만 만들고 안내합니다. numpy 도 쓰지 않았습니다 — 1단계 계산은 기본 통계라 필요 없고, 실제 알고리즘이 numpy 를 쓰면 그때 함께 반입하면 됩니다.
- **설정 파일은 JSON** 입니다. 기획서는 「YAML 또는 엑셀 표」를 예로 들었지만 YAML 은 별도 패키지가 필요해 폐쇄망 반입 부담이 생깁니다. 엑셀 표 방식이 필요하면 2단계에서 판정 기준 시트 가져오기를 붙입니다.
- **측정 건 = 같은 장비·같은 측정 일시의 진동·각속도 파일 한 쌍**으로 보고, 필수 센서(`required_sensors`, 기본 두 가지)가 다 모였을 때 알고리즘을 한 번 부릅니다. 실제 알고리즘이 두 데이터를 함께 쓸 수 있도록 입력에 두 센서를 모두 넘깁니다. 짝이 늦게 오면 「대기」로 두었다가 다음 실행 때 계산합니다.
- **중복 판정은 「측정 건·센서」 자리 기준**입니다. 같은 자리에 같은 내용이 오면 건너뛰고, 다른 내용이 오면 덮어쓰지 않고 오류로 남깁니다. 처음에는 파일 내용 지문(sha256)만으로 중복을 막았는데, 테스트에서 값이 모두 0인 각속도 파일이 서로 다른 측정 건에 있을 때 두 번째 것이 「이미 처리한 파일」로 버려지는 결함을 잡아 고쳤습니다. 지금은 내용이 같아도 다른 측정 건이면 등록하고 경고만 남깁니다.
- **알고리즘 오류는 그 측정 건만 「오류」로 두고 나머지는 계속 처리**합니다. 오류 건은 다음 실행 때 다시 시도하므로 장비 파라미터나 알고리즘을 고친 뒤 `run` 만 다시 하면 됩니다.
- **판정은 가장 나쁜 항목 기준**(기획서 8장)이며, 임계값과 같은 값은 해당 등급으로 봅니다(`값 ≥ 주의 기준` → 주의). 임계값은 항목 이름 그대로 또는 `vib_*_rms` 처럼 패턴으로 적을 수 있고, 이름이 정확히 같은 기준이 패턴보다 먼저입니다. 기준이 하나도 걸리지 않으면 「판정 불가」로 둡니다(정상으로 오인하지 않게).
- **판정마다 알고리즘 버전과 판정 기준 버전을 남기고**, 기준을 바꾼 뒤 `rejudge` 로 저장된 결과에 다시 적용합니다. 재판정도 실행 이력에 남습니다.
- **예시 데이터는 별도 DB(`data/demo/`)** 에서 돌립니다. 실제 DB에 가상 측정 건이 섞이지 않게 하기 위함입니다. 예시 파일 이름은 모두 `예시데이터_` 로 시작하고, 이런 파일이 들어간 보고서에는 「예시 데이터」 안내 띠와 파일 이름 꼬리표가 붙습니다. 임시 알고리즘 결과가 들어간 보고서에는 「임시 알고리즘」 안내 띠가 붙습니다.
- **HTML 보고서는 외부 글꼴·스크립트 없이 파일 하나**입니다. 표는 좁은 화면에서 표 안에서만 가로로 밀리게 했고, 인쇄할 때 접힌 결과 값도 펼쳐 찍히게 했습니다.
- **`data/` 는 git 에 올리지 않습니다**(`.gitignore`). 실제 측정 결과 DB와 보고서가 공개 리포에 올라가지 않게 하기 위함입니다.

## 가정

- 파일 이름 규칙 `장비ID_YYYYMMDD-HHMMSS_vib.csv` / `_gyro.csv` 는 가정입니다(기획서 10장 2번). `settings.json` 의 `file_name_pattern` 으로 바꿉니다.
- CSV 열 이름(`time_s`, `ax·ay·az`, `gx·gy·gz`)과 단위(g, deg/s)는 가정입니다(10장 1번). `settings.json` 의 `sensors` 에서 실제 열 이름으로 바꾸고 `columns` 명령으로 대조합니다.
- 결과 값은 클수록 나쁘다고 봅니다(`higher_is_worse: true`). 작을수록 나쁜 항목이 있으면 설정을 바꿀 수 있게 해 두었지만 항목별로 섞어 쓰는 기능은 없습니다.
- 빈 값이 있는 파일은 기본으로 거절합니다(`missing_policy: reject`). 행을 빼고 계산하려면 `drop_rows` 로 바꿉니다.
- 임시 알고리즘의 RMS 는 평균(직류분)을 빼지 않은 원신호 기준이고, 첨도는 정규분포가 3인 피어슨 첨도입니다. 판정용이 아니라 흐름 확인용입니다.
- 판정 임계값(`예시-v0 (가상 값)`)과 해석 문구는 예시 데이터에서 등급이 갈리도록 정한 가상의 값입니다.
- 예시 장비명·회전수·센서 위치는 모두 가상입니다.
