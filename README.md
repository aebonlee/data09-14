# data09-14 · 진동·각속도 데이터 분석 결과 DB화 Agent

진동·각속도 CSV에 기개발 알고리즘을 자동 적용해 결과 값과 정상/주의/고장 판정을 로컬 DB에 쌓고 해석 결과보고서를 만드는 폐쇄망 전용 프로그램

| 항목 | 내용 |
|---|---|
| 제출자 | 정화용 |
| 과정 | 현장 데이터 수집·디지털화 전문가과정 1차수 (2026) |
| 진행 단계 | 1단계 — 프로젝트 기획서 등록 (2026-09-28) |
| 다음 개발 | CSV 가져오기·SQLite DB 구조·교체형 알고리즘 연결부(임시 통계로 대체)·설정 파일 임계값 판정·HTML/엑셀 보고서까지 도는 폐쇄망용 로컬 Python 틀(실제 알고리즘은 입출력 형식 확보 후 연결) |
