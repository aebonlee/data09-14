## 실행 방법

이 도구는 웹 페이지가 아니라 **폐쇄망 PC에서 돌리는 로컬 Python 프로그램**입니다(기획서 7장). 인터넷 주소로 여는 화면은 없고, 명령창에서 실행합니다. 인터넷 연결이 없어도 동작하며 데이터는 PC 밖으로 나가지 않습니다.

### 1) 준비물

| 준비물 | 필수 여부 | 비고 |
|---|---|---|
| Python 3.8 이상 (개발 확인은 3.11) | 필수 | 표준 라이브러리만으로 CSV 가져오기·DB 저장·판정·HTML 보고서가 동작합니다 |
| openpyxl (+ 딸린 패키지 et_xmlfile) | 선택 | 엑셀 보고서를 만들 때만 필요합니다. 없으면 HTML 보고서만 만들고 안내 문구를 띄웁니다 |

### 2) 폐쇄망 PC에 Python 설치하기

1. 인터넷이 되는 PC에서 python.org 의 Downloads 에서 폐쇄망 PC 운영체제에 맞는 설치 파일을 받습니다(Windows 는 「Windows installer (64-bit)」).
2. 회사의 반입 절차(승인된 USB·자료 반입 시스템 등)에 따라 설치 파일을 폐쇄망 PC로 옮깁니다.
3. Windows 에서 설치할 때 첫 화면의 **「Add python.exe to PATH」에 체크**하고 설치합니다.
4. 명령 프롬프트에서 `python --version` 으로 설치를 확인합니다. (macOS·Linux 는 `python3`)

### 3) openpyxl 을 오프라인으로 반입하기 (엑셀 보고서가 필요할 때)

인터넷이 되는 PC에서 wheel 파일을 받아 옮긴 뒤 폐쇄망 PC에서 인터넷 없이 설치합니다.

```bash
# 인터넷 되는 PC — wheels 폴더에 openpyxl 과 et_xmlfile wheel 이 받아집니다
python -m pip download openpyxl -d wheels

# (wheels 폴더를 반입 절차에 따라 폐쇄망 PC로 옮긴 뒤) 폐쇄망 PC
python -m pip install --no-index --find-links wheels openpyxl
```

두 패키지 모두 순수 Python 이라 운영체제와 관계없이 같은 wheel 을 씁니다. 설치 확인: `python -c "import openpyxl; print(openpyxl.__version__)"`

### 4) 예시 데이터로 먼저 돌려 보기

이 폴더(리포를 받은 폴더)에서 실행합니다.

```bash
python tool.py demo
```

**「예시 데이터 불러오기」** 에 해당하는 명령입니다. `samples/` 의 가상 측정 파일(파일 이름이 모두 `예시데이터_` 로 시작)을 별도 예시 DB(`data/demo/`)에 넣고, 계산·판정·보고서까지 한 번 돌립니다. 실제 DB와 섞이지 않습니다. 결과 보고서(`data/demo/reports/`)의 HTML 을 브라우저로 열면 위쪽에 「예시 데이터」「임시 알고리즘」 안내 띠가 보입니다.

예시 데이터에는 판정이 갈리는 경우가 일부러 들어 있습니다: 정상 3건, 주의 1건, 고장 1건, 각속도 파일이 없어 대기 1건, 진동 파일에 빈 값이 있어 오류로 거절된 1건.

### 5) 실제 데이터로 쓰기

```bash
python tool.py init                                   # DB·폴더 만들기 (data/vibration.db, data/inbox, data/reports)
python tool.py columns 진동파일.csv                    # 내 CSV 열 이름이 설정과 맞는지 대조
python tool.py equipment import 장비정보.csv            # 장비 정보(파라미터) 가져오기
python tool.py equipment set --id EQ-A01 회전수_rpm=1800 # 장비 파라미터 한 건 고치기
python tool.py run                                    # start — data/inbox 의 새 CSV 일괄 처리
python tool.py status                                 # 측정 건·판정 목록 (--grade 고장 으로 거르기)
python tool.py log                                    # 실행 이력·파일별 건너뜀·오류 사유
python tool.py report --from 2026-09-01 --to 2026-09-30 --equipment EQ-A01   # 해석 결과보고서
python tool.py rejudge                                # 판정 기준을 바꾼 뒤 저장된 결과에 다시 적용
```

- **설정 파일** `config/settings.json` 에서 폴더, 파일 이름 규칙, 센서별 열 이름(열 매핑), 필수 센서, 빈 값 처리(`reject` 거절 / `drop_rows` 해당 행 제외), 판정 임계값, 보고서 해석 문구를 바꿉니다. 코드를 고칠 필요가 없습니다.
- **판정 임계값은 모두 가상의 값**입니다. 실제 기준은 담당자가 `thresholds.items` 에 채우고 `thresholds.version` 을 올립니다. 판정마다 적용한 기준 버전이 DB에 남습니다.
- **파일 이름 규칙(가정)**: `장비ID_YYYYMMDD-HHMMSS_vib.csv`(진동) / `..._gyro.csv`(각속도). 같은 장비·같은 일시의 두 파일을 한 측정 건으로 묶습니다. 실제 규칙이 다르면 `file_name_pattern` 을 고칩니다.
- **실제 알고리즘 연결**: `algorithms/` 폴더에 `run(measurement, params)` 함수를 가진 파일을 넣고 `settings.json` 의 `algorithm.module` 만 바꿉니다. 약속(입력·출력 모양)은 `algorithms/placeholder.py` 머리 주석에 있습니다.
- 테스트: `python -m unittest discover -s test` (24개)
- 예시 파일 다시 만들기: `python scripts/make_samples.py`

## 1단계 구현 범위

기획서 5장 기능 목록 기준입니다. 완료 = 이번 1단계 도구에 들어감, 다음 단계 = 기획서 8장 2·3단계.

| 기능 (기획서 5장) | 상태 | 1단계에서 한 것 / 남은 것 |
|---|---|---|
| CSV 가져오기 | 완료 | 진동·각속도 CSV 읽기(UTF-8/CP949), 설정의 열 매핑, `columns` 명령으로 대조, 필수 열·빈 값·시각 순서 확인, 같은 파일은 건너뛰고 내용이 다른 파일은 덮어쓰지 않음, 짝 파일이 늦게 들어와도 다음 실행 때 계산 |
| 장비 정보 관리 | 완료 | 장비 정보 CSV 가져오기, 한 건 등록·수정, 목록. 파라미터는 항목 제한 없이 저장하고 알고리즘에 그대로 넘김. 미등록 장비는 파라미터 없이 자동 등록하고 경고 |
| 결과 DB | 완료 | SQLite 파일 하나 — 장비·측정·원본 파일·결과·판정·실행 이력 ([DB 구조 설명서](docs/DB_구조.md)) |
| 알고리즘 연결부 | 완료(임시 알고리즘) | 교체형 약속(입력: 측정 데이터+장비 파라미터 / 출력: 항목 이름·값·단위), 출력 모양 검사, 버전 기록. 임시 알고리즘은 축별 RMS·최대값·첨도(시험용). 실제 알고리즘 연결은 2단계 |
| 판정 규칙 설정 | 완료 | 설정 파일의 항목별 주의·고장 임계값(이름 또는 `*` 패턴), 가장 나쁜 항목 기준 등급, 근거 항목·기준 버전 기록, 기준 변경 후 재판정 |
| 실행 방식 | 완료(수동) / 다음 단계(주기) | `run` 명령 한 번으로 입력 폴더 일괄 처리. 폴더 감시·운영체제 작업 예약은 2단계 |
| 해석 결과보고서 | 완료 | 기간·장비 선택, 등급별 건수, 주의·고장 목록과 근거, 측정 건별 결과 값, 미완료 건. HTML 파일 하나(외부 링크 없음, 인쇄 가능) + 엑셀(시트 5개) |
| 실행 이력·오류 기록 | 완료 | 실행마다 처리 건수·알고리즘 버전·판정 기준 버전·파일별 건너뜀·오류 사유 기록, `log` 명령으로 조회 |
| 추이 그래프 | 다음 단계 | 3단계 |
| 장비별 기준 차등 | 다음 단계 | 3단계(필요 여부 확인). 지금은 항목 이름 단위 기준만 |
| 판정 검토·수정 | 다음 단계 | 3단계 |
